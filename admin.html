Connect to GitHub

One-time setup on this device. Changes you save here are committed to your repository, so the live page updates by itself. Create a fine-grained token at GitHub → Settings → Developer settings → Fine-grained tokens. Select only this repository and give it Contents: Read and write.

Website

UPI (INR)

Never shown on the payment page. Leave the UPI ID empty to turn UPI off.

Card

Paste a payment link from your card provider. Leave empty to turn card payments off.

Quick amounts

Buttons shown above the UPI amount box. Up to 6 numbers, separated by commas. Leave empty for none.

Payment proof contacts

Customers send their transaction ID to you here after paying. These are shown to customers when they tap a send button. Fill in at least one, or leave all empty to hide the proof section.

Crypto

Remove every row to turn crypto off.
